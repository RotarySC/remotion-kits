# 套件能力目录与演示工作台

展示页读取真实套件源码，提供画廊、工作台和内容对照。它服务选件与试验；作品内容、叙事顺序和项目装配代码仍由视频工程持有。

## 启动与来源

展示页固定读取技能母版 `kits/`。`Project` 只借用已安装的 React、Remotion、TypeScript、esbuild 依赖。无需该工程的 `Root.tsx`，也不读取视频工程副本或扫描视频项目列表。

```powershell
# 持续监听，成功构建后页面自动刷新
pwsh -File <技能>/showcase/generate.ps1 -Project <依赖工程> -Watch
# 默认地址 http://127.0.0.1:18499/；端口占用可加 -Port 18500

# 单次生成离线页
pwsh -File <技能>/showcase/generate.ps1 -Project <依赖工程>

# 检查当前输出是否对应最新来源；新鲜=0，未构建或过期=3
pwsh -File <技能>/showcase/generate.ps1 -Project <依赖工程> -CheckFresh
```

`-Suite hotspot` 指定初始打开热点包，保留完整目录；与 -WithImages 同用时仅抽取该包的组合引用范围。`-Out <目录>` 改变输出位置。离线入口是 `<Out>/index.html`，需连同整个 `builds/` 一起移动。旧 `#tab=kernel` / `#tab=hotspot` 链接保留，`#asset=kernel/arrangement/Flow` 可直达能力。

实时服务仅监听本机，页面固定展示母版，没有展示来源选择或来源切换接口。监听范围是母版与展示实现，不随视频项目数量增加。工程副本的更新仍使用原更新器；展示服务只读源码。

## 页面怎么用

- 系统总览：查看内核入口、类型包选择入口和组合关系；侧栏下半区不显示分类。
- 通用内核：按元素类型分节查看自有构件与示例；可以直接使用内核。
- 侧栏下半区：内核只列内核标签，类型包只列当前包标签；点击定位同页分组，保留完整自有目录，高亮跟随滚动；标签旁无数字。侧栏使用随主题换色的细圆角滚动条，两区域独立滚动；窄屏上下排列。
- 类型包菜单与详情：点击“类型包”展开已有包列表，选中后自动收起；没有目录主页。详情将整体演示、自有内容、组合依赖分开，自有目录不会混入内核资产。
- 包使用说明：本地服务中可打开来源里实际存在的 `kit.md`；离线页显示文件位置。
- 全局搜索：跨包查找，结果按实际维护归属分组。
- 画廊卡片：当前分区内选件。悬停或键盘聚焦播放，点开逐帧看。
- 工作台：选择真实夹具和主题。Flow、Panel、ScrollArea、公共动效有临时实例试验；已有组件的 `Spec.Demo` 仍可选择。
- 实例试验：宽屏与预览框顶端对齐，底部不超过“继续试一试”。超出内容在栏内滚动，隐藏滚动条；可用鼠标、触控和键盘滚动。窄屏放到预览下方，限制高度。
- 继续试一试：按当前资产所属目录的类别和展示顺序，包含当前项的四项窗口；到末尾向前补齐，不足四项时全部显示。
- 演示进度：初次打开、选择展品、切换场景和重置试验都从当前场景的第0帧开始。刷新同一展品保留临时进度；目录缩略图仍使用代表帧。
- 对照：比较长短内容；动效比较两种起点。没有适配器的夹具会明确提示。
- 用法：查看当前试验的调用示意、实际公开 Props、归属和源码位置。
- 同步详情：查看来源、成功版本、错误和覆盖提示。源码错误时保留最后成功画面。

`library.json` 的 `kernel` 字段明确指定唯一内核；目录重命名等情况可用 `-Kernel <实际目录名>` 覆盖。其余套件目录自动成为类型包，不手抄资产列表。角色与 compose 声明分别处理，缺少组合声明会诊断，不会变成另一个内核。配置文件参与来源摘要。

能力类别与维护归属分别记录。类型包只补入原语和组件组合演示，不把内核的主题、版式、皮冒充自己的资产。当前的版式数与演示场景数分别显示。

原语由 `COMPONENT_SPECS` 登记；版式由 `LAYOUT_SPECS` 与真实 `ShowcaseScenes` 对应；主题由注册表枚举；皮与公共动效单列。中文名读取 `labels.ts` 的实际导出对象。Props 校验读取 TypeScript 公开组件类型，私有类型别名、换行或引号风格不会决定能否识别。

页面铺满视口，默认使用浅色毛玻璃，可在侧栏切换灰黑玻璃暗色。材质样式集中在 `gallery/glass-styles.ts`，与真实视频组件的套件主题分开。背景模糊不被支持或启用减少透明效果时，表面回退为实色；窄屏保持独立滚动布局。

## 新内容如何跟上

监听覆盖文件修改、增加、删除和重命名，并用来源摘要补查事件遗漏。套件目录、未导入文件、展示源码与依赖版本均参与摘要。

文件通知合并等待约400ms；约1.8秒一次摘要补查。浏览器约1.2秒检查成功版本号，发现新版本后保留当前页面、展品与临时设置并刷新。监听停止后离线页不会自动更新。普通实时构建不抽取静帧，静态缩略图需显式使用 `-WithImages` 重建。

同一次保存的多条通知会合并；重写原字节不会构建新版本。构建前与完成后都复核摘要，期间的新修改继续排队，失败只记录本轮尝试的输入。

新公开组件应同时有源码、规格与中文名；新主题需登记，新版式需声明与演示。漏登记会阻止发布。新动效函数可以自动进入目录，展示适配器缺失会作为覆盖提示显示。系统自动发现能力，夹具仍需维护者创作。

`WARN` 表示登记、类型、来源等不一致，构建失败；`NOTE` 表示展示说明或夹具分支尚未覆盖，不阻断。逐项提示可在同步详情查看。检查摘要不代替看图，也不能证明作品的真实内容都适配。

管线先检查来源与生成入口，再构建候选版本，最后复核摘要并原子替换根入口。每次输出在 `dist/builds/<buildId>/`，旧页与资源保持同一版本。失败候选不会发布。版本目录暂不自动清理，确认无需旧打开页面后可按版本清理。

## 静态图与扩展

```powershell
# 显式抽取真实 Remotion 静帧，较慢；实时交互默认不需要它
pwsh -File <技能>/showcase/generate.ps1 -Project <依赖工程> -WithImages -Scale 0.5
```

需要既有 `@remotion/bundler`、`@remotion/renderer`。生成的图属于本次版本，在画廊勾选「使用本次构建的静态缩略图」；工作台仍实时渲染。静帧按原生 1920×1080 画布抽取，超出画布的自然内容应到工作台查看。

新增交互夹具放在 `gallery/demos.tsx`，只调用公共接口。夹具与临时控件属于展示实现，不成为运行时组件契约。尺寸边界使用实际母版容器，避免复制主题几何公式。`gallery/stage.tsx` 为真实 Remotion 上下文适配，与 Remotion 版本相关。

## 验证

```powershell
# 只发现与校验：JSON 清单；成功=0，WARN=2
pwsh -File <技能>/showcase/generate.ps1 -Project <依赖工程> -DiscoverOnly

# 用已有 Playwright 与浏览器，不自动安装依赖
node <技能>/showcase/verify.mjs http://127.0.0.1:18499/ --playwright <已有Playwright包路径> --out <证据目录>
# 必要时加 --browser <已有浏览器可执行文件>

# 页面语义：职责导航、自有目录、依赖情境、搜索与返回
node <技能>/showcase/verify-structure.mjs http://127.0.0.1:18499/ --playwright <已有Playwright包路径> --out <证据目录>

# 工作台：两栏边界、隐藏滚动、四项窗口、场景进度
node <技能>/showcase/verify-workbench.mjs http://127.0.0.1:18499/ --playwright <已有Playwright包路径> --out <证据目录>

# 创建独立夹具：多类型包 / 局部内容 / 角色 / 新增删除 / 刷新 / 新鲜度
node <技能>/showcase/verify-pipeline.mjs --project <依赖工程> --work <不存在的新夹具目录> --playwright <已有Playwright包路径>
```

浏览器验收覆盖职责入口与各自有分区，代表性真实交互、所有主题、版式场景、预期诊断、搜索、键盘和小窗口。管线验收不写入母版或真实工程：用没有 Root 的夹具，注入漏登记与错误 Props，确认旧入口字节保持，并检查成功刷新保留临时设置。证据目录保留截图与 JSON，需实际看图。

验收判据（每一条都要能复现；复跑方式即上面四条命令）：

- 母版构建不需要项目 `Root.tsx`，仅借用依赖。
- 使用真实套件组件和真实夹具；唯一内核、已发现类型包及实际主题可预览，补入层保留真实归属。
- 新资产被发现，删除或重命名不留下假展品；版式数与场景数可分别查验。
- `Flow` 的内容与高度、皮的实例覆盖、`ScrollArea` 与动效跨帧均通过真实浏览器行为检查与看图。
- 注册或 Props 不一致、类型错误、构建错误阻止发布，旧页面与旧 buildId 保持。
- 文件变化触发重建；成功刷新，失败提示；未 import 的新增文件也参与摘要与发现。
- `-CheckFresh` 对未构建、过期、成功构建分别给出正确退出码。
- 页面支持职责导航、页内分类、按归属分组的搜索、来源识别、工作台与对照；小窗口无横向页面溢出，键盘能操作，减少动态效果设置生效。
- 技能母版与仓库镜像逐文件相同；不修改工程副本，不触发更新器。

内部验证命令使用 `--fixture-source` 指向隔离母版夹具；正式 PowerShell 入口固定读取技能母版，已移除 `SourceRoot`。服务调度代码修改后应重启监听进程。

总体构建退出码：`0` 成功，`1` 构建或使用错误，`2` 发现校验存在 WARN，`3` 新鲜度检查未通过。监听模式遇到源码错误继续等待修复。

新版深链接使用 `#page=overview`、`#page=kernel`、`#page=type-detail&tab=hotspot`；能力链接增加 `asset` 与 `mode`，`category` 定位整页中的元素分组。工作台只提供“工作台 / 对照”切换，通过内容区返回入口回到完整目录。旧 tab / asset 链接会迁移；旧 `#page=type-index` 返回总览。源码影响展示内容时自动构建；改动服务调度或请求处理代码后应重新启动监听命令。
